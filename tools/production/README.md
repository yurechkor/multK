# Производственные помощники

20 октября 2026. Stdlib Python и существующие ffmpeg/ffprobe/Node. Команды ниже запускает исполнитель внутри автономного процесса; пользователь пишет «Йоу». Эти помощники не генерируют фильм без исполнителя и не оценивают художественное качество.

## Журнал платных задач

Поддерживаемые kind: tts, sfx, music, image, video, transcription, model3d, rig. Для model3d/rig сохранять все параметры модели/позы/текстур/полигонов и ID исходной модели; загруженный GLB связывать с SHA256, как любой другой результат. Для transcription сохранять хеш исходного аудиофайла и модель; это тайминги субтитров, не проверка ударений.

Сохранить полные параметры в episode/requests/<name>.json: kind, model_id, prompt, voice_id для TTS, generations_count=1 и ВСЕ прочие смысловые настройки/входные ассеты с хешами. Исключить estimate_only, flow_id/view_state_id и другие транспортные идентификаторы. Для TTS закреплены Nikolay / eleven_multilingual_v2. Оценка цены не резервирует генерацию и не является синтезом.

1. `python3 tools/production/yo.py generation-reserve <episode> <request.json>`
2. Только свежий `submit_once` допускает ОДИН MCP-вызов с этими параметрами. `inspect_existing` — читать provider status/историю; не отправлять заново. `reuse` — переиспользовать проверенный локальный файл.
3. Сразу по ответу провайдера: `generation-update <episode> <key> --status submitted --provider-ids '<JSON реальных flow/node/session ID>'`.
4. Скачать результат: `generation-update <episode> <key> --status completed --output <относительный-путь>`. Журнал связывает файл с SHA256, изменённый/пропавший результат нельзя молча считать готовым.
5. Таймаут/потеря ответа — неизвестный исход, статус reserved/submitted сохраняется. Сначала искать уже отправленную задачу. Только подтверждённая конечная ошибка: `generation-update ... --status failed --note '<причина и проверка>'`; сохранить локальное evidence отказа. Для обоснованного повтора: `generation-retry <episode> <key> --evidence <файл> --note '<восстановление/почему повтор>'`. История попыток сохраняется. Не подделывать изменённый prompt или новый ID ради обхода защиты; после двух неудач пересмотреть метод.

Блокировка файла и атомарная запись предотвращают одновременную выдачу двух разрешений в одном выпуске. Это локальная защита: прямые вызовы MCP вне маршрута она не перехватывает. Между вызовом провайдера и сохранением ID есть неопределённое окно сбоя; поэтому неизвестная задача блокирует повтор, а не обещает exactly-once у провайдера. Поиск уже созданного результата предпочтительнее нового синтеза.

## Один таймлайн и общие сцены

Исходник timeline.json внутри выпуска:

```json
{"fps":30,"total_frames":90,"shots":[{"id":"setup","frames":30},{"id":"contact","frames":60}],"events":[{"id":"impact","shot":"contact","offset_frames":5,"roles":["action","foley","background"]}]}
```

`python3 tools/production/yo.py timeline <episode>/timeline.json` выводит рассчитанные границы и времена событий. При сборке сохранить результат, например, в project/timeline.compiled.json. Исходный timeline.json явно включить в render_inputs и ключ кэша. Каждый адаптер использует этот результат; вручную повторять числа в компонентах, звуковом миксе и фоне запрещено. Проверка требует полного покрытия кадрами, уникальных ID и событий внутри сцен.

scene-clock.cjs экспортирует sceneClock(compiledTimeline, frame): текущая сцена, локальное/общее время и event(id) с возрастом события. Один и тот же компонент Scene({clock, assets, style}) используется в Remotion и файловом выводе. Адаптеры меняют только оболочку/среду, не содержимое сцены. Тест короткого участка включает границу сцены и событие: при сдвиге предшествующей сцены изображение/контакт/звук/фон сдвигаются вместе. Старые файлы France/Tesla остаются архивными реализациями, не общей библиотекой.

## Кэш, экспорт и проверка

Перечислять реальные src/fonts/assets/таймлайн и renderer/version/seed/size/fps; не хешировать папку выпуска вместе с меняющимися журналами. Каталоги cache, .cache, renders, reviews, node_modules пропускаются при обходе. Производные файлы хранить вне входов. Явно переданный отдельный входной файл всё равно хешируется.

Новый экспорт по возможности совмещает сцены и титры в одном кодировании. Сначала короткий тест кириллицы, теней и смены состояния; если альтернативный renderer меняет качество, сохранить проверенный путь. Удалять blur/материал ради быстроты без художественной проверки нельзя.

`python3 tools/production/yo.py make-silent <master.mp4> <new-preview.mp4>` копирует только сжатый видеопоток, проверяет отсутствие аудио и совпадение streamhash. Существующий файл не перезаписывается; после изменения мастера использовать новое имя. `verify` также сверяет видеопотоки. Это короткое последовательное чтение файлов без декодирования/перекодирования и проигрывания; оно не доказывает содержание/хорошее движение. Полный тихий просмотр остаётся обязательным. По решению пользователя от 20.10.2026 отдельные акустическое ревью/перепроверка ударений отменены; pronunciation не входит в обязательные gates verify. Для audio сохраняются технические проверки файла/уровней/таймингов.

`python3 -B -m unittest discover -s tools/production -p 'test_*.py'` — изолированные проверки; медиатест использует только маленькие синтетические кадры, без звукового воспроизведения и платных вызовов.
