# Допуск результата

Не перечитывать историю аудитов. Контракт — PROJECT.md, раздел 6; фактические проверки — в текущем review. Файловый CLI не доказывает художественное качество.

| Проверка | Необходимое свидетельство |
|---|---|
| Начало / opening | Реальные первые 3–8 с с речью и действием; тема, хук, голос, моушн и оформление работают вместе, без опоры на сильную середину |
| Середина / развязка | У каждого бита новое понимание или последствие; обещание хука выполнено; последняя реплика + действие дают заработанный результат для героя/зрителя, вывод/последствие/поворот/шутку; вопросы/CTA/случайный панч не подменяют финал |
| Смысл и факты | Хук/новые следствия/ответ, ссылки и границы утверждений; в альтернативной истории — канон, явная развилка и внутренняя причинность |
| Причинное действие | Движущийся тест 3–8 с: причина, контакт/реакция, новое состояние; материал/объём узнаваемы |
| Полный финал | Реальный тихий просмотр всего закодированного MP4, стыков, краёв, непрерывности объектов |
| Текст | Все входы/выходы/удержания, дословность речи, нет дублей/караоке/скачков, читается на телефоне; все подписи/выноски контрастны на фактическом фоне, при необходимости есть подложка |
| Геометрия | Полноэкранная история, центр x=540, нет бокового резерва/обязательной шапки/контейнера. Поля и стабильная нижняя зона сабов служат читаемости. LAYOUT_STANDARD.md; Safe Zone/маски/gate отменены |
| Постановка / числа / переходы | Общий замысел по MOTION_DIRECTION.md: выразительные материал/контакт/камера, изменения величин с единицами и читаемым итогом; смысловой переход и связанный звук; нет вялых карточек или бессвязных эффектов |
| Мерцание и рябь | Подозрительные соседние кадры A→B→A проверить в движении; текстура стабильна, предметы не выпадают на 1–3 кадра |
| Звук | Техническая проверка файла, уровней/клиппинга, баланса речи/фоли и совпадения событий; отдельные акустическое ревью и перепроверка ударений отменены пользователем 20.10.2026 |
| Техника | Нужные длительность/fps/размер/кодек, мастер с аудио, тихая копия без аудио с идентичным сжатым видеопотоком, единый таймлайн сцен/фоли/фона, редактируемые источники/тайминги |

Чёрные кадры и контактный лист раз в несколько секунд не доказывают отсутствие микропровалов и хорошее движение. Указывать пределы, не рисовать pass из отсутствия автоматической ошибки.

До полного экспорта провести лёгкую проверку субтитров по AUTOPILOT.md, «Экономия без снижения качества»: покрытие текста/тайминги/две строки, смысловые фразы, измерение строк реальным шрифтом и случайные разрывы на 1–3 кадра. Она помогает найти дефект раньше; полный тихий просмотр финала сохраняется.

Для дефекта сначала готовый файл/короткий участок и причина, затем адресная правка. После изменения проверить затронутые места/стыки и конечный файл; не повторять дорогие проверки неизменного источника без причины. Кэш привязан к содержимому всех исходников/ассетов/таймингов/настроек, а ревью — к хешам финальных файлов. Изменение после ревью снимает допуск.

Все просмотры тихие; один тяжёлый процесс и предварительное уведомление по PROJECT.md. Акустическое ревью и перепроверка ударений не являются условиями допуска; pronunciation не требуется, отсутствие этой проверки не останавливает производство. Не заявлять о прослушивании, если его не было. Приёмку пользователя не заменять собственным отчётом.

При переносе старого компонента проверять действующие правила текста, заголовков и тихого предпросмотра. Принятие старого выпуска не означает разрешения его исторических настроек. Художественное сравнение нового теста с удачным приёмом делать по конкретному вопросу, без пересборки закрытого выпуска.

## Художественный отказ имеет приоритет — 21 октября 2026

Провал «Мышцы без отдыха» показал: перечисление «есть металл, есть подъём, есть переход» не доказывает качество. До полного производства применить конкретные условия отклонения и сравнение в MOTION_DIRECTION.md, раздел «Разбор провала “Мышцы без отдыха”». Отчёт обязан разделять техническую исправность, наблюдаемое художественное качество и приёмку пользователя. Уточнение границ инструмента не разрешает поставить художественный pass без достаточного наблюдения.

Запущенный на 60 секунд плеер и несколько снимков не равны оценке всего движения. Для оценки контакта/веса/связи вторичных движений смотреть короткие участки с достаточной временной детализацией; если доступны только редкие снимки, записать «не проверено» для соответствующего качества. Текстовая проверка на пропуски субтитров не подтверждает отсутствие всех визуальных дефектов.

При явном отказе пользователя записать `user_acceptance: rejected`, снять готовность и недостоверные художественные pass, сохранив прежние свидетельства как историю. Повторный успешный verify не может отменять отказ. Снять отметку rejected можно только после явно порученной новой версии/нового рассмотрения; запись старого отказа и хеш отклонённого файла сохраняются, принятие пользователем не выдумывается.

Выдача: главный результат — проверенный мастер с аудиодорожкой. Тихая техническая копия остаётся для внутреннего просмотра и не открывается автоматически как основной пользовательский результат. Если её показывают по необходимости, явно обозначить «без звука» до открытия. Не играть мастер вслух автоматически; запрет слышимого воспроизведения сохраняется и не означает немую доставку.

При выборе техники также применять CHARACTER_STANDARD.md: сложность и затраты не являются доказательством качества. Проверка установки не означает проверку подключений или художественный допуск.
