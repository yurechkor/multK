# multK — мастерская коротких мультфильмов

Переносимый проект для работы с Codex: русские сценарии, режиссура, производство motion-видео, дословные субтитры, звук и проверки результата. Команда **Yo / Йоу / Йо** запускает один новый выпуск; стандарт — 60 секунд, 1080×1920, 30 fps.

Это документация и инструменты для исполнителя в Codex, а не автономный видеогенератор. Для создания видео нужны доступные на вашем аккаунте инструменты генерации и локальное окружение. Качество определяется постановкой и проверкой реального движения.

## Скачать и начать

1. Нажмите **Code → Download ZIP**, распакуйте архив в обычную папку на ноутбуке. Или клонируйте: `git clone https://github.com/yurechkor/multK.git`.
2. Откройте эту папку как локальный проект в Codex. Если выбран ваш другой рабочий проект, сначала переключитесь на папку multK.
3. Отправьте Codex:

   > Прочитай AGENTS.md и docs/SETUP.md. Подготовь этот проект на моём ноутбуке, проверь необходимые инструменты и подключения. Видео пока не создавай, платные генерации не запускай.

4. Подключите **свои** сервисы. Основная озвучка — ElevenLabs, голос Nikolay; его доступность проверяется на вашем аккаунте. Инструменты изображений/видео/After Effects нужны только при выборе соответствующей техники. Подписка Codex сама по себе не переносит чужие подключения и кредиты.
5. После подготовки напишите **«Yo»** или **«Yo, тема …, 45 секунд»**. Каждый выпуск будет отдельной папкой в `episodes/`.

Если терминал незнаком, пункты из docs/SETUP.md выполнит Codex. Начальная проверка ничего не генерирует и не проигрывает.

## Своя независимая мастерская

Скачанная папка уже является независимой рабочей копией. Для ещё одного проекта из неё:

```sh
python3 tools/new_project.py ../my-cartoons
```

Получится новый каталог с правилами, навыками, инструментами и пустой историей выпусков. Готовые выпуски, ключи, кэши и `.git` не копируются. При необходимости добавьте полученную папку как отдельный локальный проект в Codex. Специального переносимого файла аккаунта Codex здесь нет: переносится папка проекта.

## Что внутри

- `AGENTS.md`, `START_HERE.md` — начало работы исполнителя.
- `PROJECT.md`, `AUTOPILOT.md` — контракт и порядок производства.
- `EDITORIAL_STANDARD.md`, `MOTION_DIRECTION.md`, `VISUAL_DEVELOPMENT.md`, `CHARACTER_STANDARD.md` — речь, постановка, оформление, персонажи и экономия.
- `QUALITY_STANDARD.md`, `LAYOUT_STANDARD.md` — художественные и технические проверки.
- `.agents/skills/` — два локальных навыка; глобальная папка исходного автора не нужна.
- `tools/production/` — создание выпуска, единый таймлайн, журнал генераций, проверка файлов и тихая копия.
- `templates/remotion/` — минимальная редактируемая техническая основа, без навязанного персонажа и платных ассетов.
- `docs/SETUP.md`, `docs/PORTABILITY.md`, `docs/LESSONS.md` — установка, границы переноса и выводы из ошибок.

Проверено на macOS; Python-инструменты рассчитаны на macOS/Linux, на Windows используйте WSL. Сам рендер и подключённые приложения требуют проверки на целевом ноутбуке. After Effects не обязателен для Remotion.

## Совместная работа

Для независимой копии достаточно Download ZIP. Для собственной версии на GitHub — Fork. Предлагайте общие улучшения через pull request; прямое изменение исходного репозитория требует прав владельца. Не отправляйте в PR свои ключи и медиакэши. Подробнее: [CONTRIBUTING.md](CONTRIBUTING.md).

Код и авторская документация этого набора — MIT, см. [LICENSE](LICENSE). Лицензии Remotion, подключённых сервисов, шрифтов, моделей и генерируемых материалов действуют отдельно. Чужие видео-референсы, шрифты из macOS, личные фильмы и история аккаунтов в набор не включены.
