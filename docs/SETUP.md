# Подготовка на другом ноутбуке

## Требования

- Codex с доступом к этой локальной папке и выполнению команд. Подключения доступны в зависимости от вашего аккаунта и окружения; набор не создаёт аккаунты и не переносит чужую авторизацию.
- Python 3.11 или новее. На Windows — WSL, так как журнал использует POSIX-блокировку `fcntl`.
- Node.js и npm для Remotion. Техническая основа проверяется на версиях из package-lock.json; пример окружения поставки — Node 26.5.0. На другом Node выполнить проверку установки/сборки.
- ffmpeg и ffprobe в PATH. Они нужны для обработки/проверки медиа и создания тихой копии, без воспроизведения.
- Для финального рендера — поддерживаемый Remotion браузер. Можно указать свой Chrome через переменную `BROWSER_EXECUTABLE`; абсолютный путь чужого ноутбука не вшит.

Установите отсутствующие программы обычным способом для вашей системы. Проверка не устанавливает ничего и не обращается к платным сервисам:

```sh
python3 tools/setup.py --check
python3 tools/production/yo.py context
python3 tools/production/yo.py preflight
```

Настройте часовой пояс, например:

```sh
python3 tools/setup.py --timezone Europe/Moscow
```

Голос/модель, fps и длительность по умолчанию находятся в production/defaults.json. На первом запуске Codex должен проверить голос Nikolay `3EuKHIEZbSzrHGNmdYsx` через ваш ElevenLabs. Идентификатор не является секретом и не даёт доступ к чужому аккаунту. Если голос недоступен, сообщить блокер; не подменять голос без решения владельца.

## Подключения

Откройте настройки подключений вашего Codex и подключите собственный ElevenLabs. Для выбранной техники могут потребоваться инструменты изображений/видео или After Effects. Точные доступные названия и действия Codex проверяет в текущем окружении. Отсутствие необязательного сервиса не означает необходимость устанавливать всё подряд.

В наборе нет универсального прямого API-клиента ElevenLabs: вызовы выполняет агент через реально доступные инструменты. Файл .env.example — только пример локального хранения переменных для будущего собственного адаптера, не рабочая авторизация коннектора. Свои токены не отправлять в чат, репозиторий и pull request.

## Техническая основа Remotion

Не копировать node_modules исходного автора и не создавать символические ссылки на его компьютер. Из корня:

```sh
cd templates/remotion
npm ci
npm run check
npm run bundle
```

Это установка зависимостей и сборка технического примера, без платной генерации/финального рендера. Сборка проверяет код, но не художественное качество. Браузер/рендер проверяются отдельно при первой короткой пробе.

Рабочий экземпляр шаблона создавать в `episodes/<выпуск>/project/`. Шаблон содержит только 3-секундный технический тест контакта; он не является готовым стилем или художественно принятым мультфильмом. Заменить сцену, речь, субтитры и таймлайн своей историей; срок/кадры берутся из нового timeline.json.

```sh
python3 tools/production/yo.py init --slug my-story --topic-key my-story --topic 'Моя история' --duration 60
```

Команда резервирует один выпуск и создаёт production.json, но не генерирует медиа и не запускает рендер. Для производства напишите Codex свой запрос или Yo. Скрипты не заменяют режиссуру, фактчек, генерации и полный тихий просмотр финала.
