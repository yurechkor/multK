# Что переносится

Поставляются полные действующие производственные стандарты, два авторских локальных навыка, Python/Node-помощники, единый таймлайн и минимальный редактируемый шаблон Remotion. Все рабочие пути вычисляются относительно текущего проекта; глобальная папка навыков первоначального автора не требуется. AGENTS.md явно маршрутизирует локальные навыки, даже если интерфейс не показал их автоматически.

Не поставляются: чаты/память/настройки Codex, подключённые аккаунты, подписки и кредиты, ключи, готовые личные фильмы, остановленная 3D-переделка, чужие скачанные видео, системные шрифты macOS, node_modules, кэши кадров, старые журналы генераций и устаревший архив инструкций. Они не являются зависимостями этой установки. Пустая история позволяет владельцу начать свои темы.

После переноса заново проверяются доступ к сервисам, голос, браузер, шрифты с кириллицей, путь вывода и первая короткая проба. Переносимый набор не гарантирует одинаковый результат на всех моделях/аккаунтах. Техническая исправность и художественный допуск — разные проверки.

В дальнейшем собственные выпуски сохраняются локально. Общие улучшения — через Fork/pull request. Если хотите отдельно публиковать фильм или его ассеты, делайте это осознанно после проверки состава и лицензий. Шаблон .gitignore исключает рабочие выпуски из обычного git add.
