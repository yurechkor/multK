# Примеры форматов

review.json — структура квитанции, все проверки намеренно not_verified. Скопировать в свой выпуск и заполнить хешами реальных файлов/источников и непустыми свидетельствами фактически выполненных проверок. Не заменять все статусы на pass автоматически.

tts-request.json — минимальная форма смысловых параметров для generation-reserve. Добавить ВСЕ фактически выбранные параметры синтеза и финальный текст. Пример не отправляется сервису сам, ключей не содержит. Имя voice_id не является авторизацией.
