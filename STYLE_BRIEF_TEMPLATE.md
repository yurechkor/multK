# Карточка выпуска (в Yo заполняется исполнителем без вопросов)

Хранить как `episodes/<дата>-<slug>/brief.md`; не создавать копии отчётов на каждую роль.

- Уклон/тон, жанр, конкретная завязка пользователя (если есть); канон/допущение для альтернативной истории.
- Тема/ключ и отличие от уже произведённых. Длина готового видео, дедлайн/диапазон ETA.
- Кандидаты тем/основание выбора: знакомый предмет, неожиданность, ставка, видимый механизм, ответ, источники/границы. Чужие просмотры с датой, если полезны; без гарантии охвата.
- Допуск начала: тема + сюжетное обещание + подача Nikolay + первое действие + оформление; таймкод короткого теста.
- Способ рассказа и зрительская ситуация; три разных по замыслу хука / один выбранный. Обещание → место его выполнения → промежуточные открытия → результат/причина переслать или обсудить. Число битов по содержанию/длине; проверить провисание середины.
- До основного TTS: обещание хука → показанный результат для героя/зрителя → последняя реплика + последнее действие. Тип концовки (вывод/последствие/поворот/шутка), почему она следует из сюжета; время на завершение без обрезки/ускорения.
- Сравнение 2–3 цельных оформлений; выбранный паспорт и основание. Для случайного выбора — кандидаты, seed/результат.
- Паспорт: палитра/материал/свет, шрифты/одно возможное акцентное слово, прогресс, система одноцветных сабов, полноэкранная геометрия/центр из production/layout-1080x1920.json, стабильная симметричная нижняя зона сабов без платформенных резервов/контейнера/обязательной шапки, контраст всех подписей/выносок на реальном фоне и нужные подложки, фон по блокам, камера/переходы; отличие от последних 2–3 выпусков по пространству, материалу, камере, действию и ритму.
- Карта: время → до → причина/контакт → действие/реакция → после → слои → роль текста → переход. Указать 2–3 сильных действия и самый рискованный тест.
- Единый timeline.json: ID сцен/событий, длительности в кадрах; звук, фон и переходы ссылаются на события, не дублируют абсолютные таймкоды.
- Голос/модель/файл (без отдельной перепроверки ударений); карта фоли: событие/источник/время/уровень.
- Источники/ассеты/генерации с реальными ID и затратами, если доступны. Этап, проблемы, следующая операция. Подробные тайминги в рабочих JSON/SRT, не дублировать их целиком здесь.

Правила — PROJECT.md; порядок автономного запуска — AUTOPILOT.md. Старые решения сохранены в docs/archive/pre-yo-2026-10-19/.
