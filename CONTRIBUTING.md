# Улучшения общей основы

Сделайте Fork, отдельную ветку и pull request с конкретным изменением и его проверкой. Не требуется копировать личные фильмы, генерации и аккаунты. Документацию менять вместе с поведением инструментов. Не заявлять художественное качество по одним тестам.

Проверки из корня:

```sh
python3 -B -m unittest discover -s tools/production -p 'test_*.py'
python3 -B -m unittest discover -s tools -p 'test_*.py'
cd templates/remotion
npm ci
npm run check
npm run bundle
```

Не отправлять ключи, .env, signed URL, личные пути и node_modules. Включайте только ассеты, которые разрешено распространять, с указанием источника/лицензии. Для новых обязательных зависимостей обновляйте docs/SETUP.md.
