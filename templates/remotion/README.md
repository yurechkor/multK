# Техническая основа

`npm ci` → `npm run check` → `npm run bundle`. `npm run studio` открывает рабочую среду только по запросу; она может содержать аудио после добавления своего микса, поэтому не воспроизводить её со звуком. Для просмотра результата использовать отдельную тихую копию с muted=true до play.

`npm run render` экспортирует технический тест; до запуска сообщить о нагрузке и возможной первой загрузке браузера. В комплекте только авторская проба контакта без голоса, не готовый выпуск и не художественный референс. Не маркировать её как прошедшую production verify.

Для своего фильма копировать папку без node_modules/build в episodes/<выпуск>/project. Разработать собственный Scene, обновить timeline.json, выполнить `npm run timeline`. Composition берёт длительность/fps из compiled timeline. Scene({clock}) — единый компонент для любого адаптера; копию тела сцены для файлового рендера не делать.

Подготовить captions.json по фактической речи, один цвет и нижняя стабильная зона. Поместить финальный микс в public/mix.wav и задать audioSrc="mix.wav" в defaultProps или через Remotion props при рендере. По умолчанию audioSrc=null: без подключённого микса шаблон остаётся немым. Ссылкой на готовый фильм должен быть именно мастер с аудио.

Проверить кириллицу/ширину строк выбранным лицензированным шрифтом; системный Arial не гарантирует одинаковую геометрию на разных ОС. Общая Scene и таймлайн обеспечивают техническую основу, а не качество дизайна/анимации.
