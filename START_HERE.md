# Начало работы

Новая установка → [docs/SETUP.md](docs/SETUP.md). Перенос/состав → [docs/PORTABILITY.md](docs/PORTABILITY.md).

`Yo` / `Йоу` / `Йо` → [AUTOPILOT.md](AUTOPILOT.md), [PROJECT.md](PROJECT.md), затем `python3 tools/production/yo.py context` и `preflight`. Навык — [.agents/skills/motion-yo/SKILL.md](.agents/skills/motion-yo/SKILL.md).

Редактура → EDITORIAL_STANDARD.md. Постановка → MOTION_DIRECTION.md. Персонаж/выбор техники/экономия → CHARACTER_STANDARD.md. Оформление → VISUAL_DEVELOPMENT.md и LAYOUT_STANDARD.md. Диагностика → QUALITY_STANDARD.md и конкретный review текущего выпуска.

Не читать всё по кругу. Новый выпуск начинать в свежем чате, текущий продолжать из его production.json. Примеры команд при настройке не являются запуском фильма.
